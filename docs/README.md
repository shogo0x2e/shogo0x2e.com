# shogo0x2e.com documentation

このディレクトリは、`shogo0x2e.com` の目的、情報設計、デザイン判断をまとめる入口です。

このサイトは、完成した経歴を並べるだけの履歴書ではありません。北田章伍が何に惹かれ、何を作り、未知との接触によってどう変化したかを、生涯にわたって更新する個人ポートフォリオです。

一方、訪問者に自己分析を読み解かせるサイトにはしません。採用担当者や技術者が実績へ迷わず到達できる、一般的で読みやすい技術ポートフォリオを土台にします。思想はナビゲーションの奇抜さではなく、コピー、プロジェクトの選び方、設計判断、学びの記述に表します。

## Current decisions

- 技術に軸足を置いた個人ポートフォリオにする。
- HCI、Embodiment、Physical AIなど、現在の専門領域を恒久的なブランドにはしない。
- 中心に置くのは「世界と未知を求めて変化し続ける、好奇心の強い人間」であること。
- 情報設計は一般的な分類にそろえる。
- プロジェクトと公開する技術記事を `Work` に統合する。
- Workの表示分類は `Project` / `Writing` のどちらか1つとする。論文は関連する研究Projectに含める。
- 検索用の語は非表示の `keywords` に分離し、`?q=` から検索状態を復元できるようにする。
- Blogは構想が固まるまで実装しない。
- Markdownを正本とし、Git-based CMSの導入を検討する。
- 公開サイトは外部ホスティングに置き、自宅環境の停止が閲覧へ影響しない構成にする。
