# Static portfolio mock

This directory is a disposable HTML/CSS/JavaScript prototype for validating the
selected editorial portfolio direction before choosing the production stack.

Pages:

- `index.html` — About / home
- `projects.html` — searchable project archive
- `cv.html` — public web CV with a private-details contact CTA
- `contact.html` — minimal email contact page

The images in `assets/` are crops from an AI-generated design comp. They are
placeholders and must be replaced with the original project photography before
the portfolio is published.

Open `index.html` directly, or serve this directory with any static file server.

The CV copy is intentionally limited to facts already confirmed as publishable
in the design discussion. Employment and education details remain placeholders
until reviewed for public release.
