Smart Home Maid is an autonomous mixed-reality assistant created for JPHACKS 2023.The project explored how an embodied character could make smart-home interactions feel less lonely and less rigid.

## Contribution

- Implemented interactions in Unity using Interaction SDK.
- Built prompts initiated by the avatar using Spatial Anchors.
- Integrated the experience with Meta XR SDK,FastAPI,and the OpenAI API.

## Outcome

The project was selected as a JPHACKS finalist and received the JStream Award.
