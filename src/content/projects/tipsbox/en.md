TIPSBOX generates a daily technical article from code found in a user’s GitHub repositories,turning prior implementation work into prompts for further learning.

## Contribution

- Designed structured prompts for LLM output.
- Implemented batch-processing features.
- Worked with Next.js,PostgreSQL,BullMQ,Redis,the GitHub API,and the OpenAI API.

## Outcome

The project received an Effort Award at a GEEK CAMP hackathon.
