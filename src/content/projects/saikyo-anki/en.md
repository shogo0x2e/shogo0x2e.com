Saikyo Anki supports engineers reading technical articles.It explains unfamiliar terminology in context and preserves it for later repetition and review.

## Contribution

- Led the team and presented the project.
- Implemented backend features using Auth.js and Prisma.
- Integrated the OpenAI API and a Chrome extension with the Next.js application.

## Outcome

The project received an Excellence Award at a GEEK CAMP hackathon.
